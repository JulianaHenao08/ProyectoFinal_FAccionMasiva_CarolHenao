Este proyecto consiste en el desarrollo de una página web para la fundación Acción Masiva, cuyo objetivo es facilitar la interacción con la comunidad mediante secciones como donaciones, voluntariado, puntos de entrega y contacto. La plataforma fue diseñada con un enfoque visual moderno y responsivo, utilizando HTML, CSS y JavaScript, incorporando elementos interactivos como formularios, animaciones y modales para mejorar la experiencia del usuario. Aunque no se implementó una base de datos, se simula la funcionalidad de donaciones y registro de información, permitiendo representar de manera realista el funcionamiento de una página web solidaria orientada al apoyo social.
